- [x] **Task 1 — Admin widgets BFF CRUD**
  `GET/POST /api/widgets`, `GET/PATCH/DELETE /api/widgets/:id`. Strip extra
  body keys. Preserve 401/403. Allow empty DELETE 204.

- [x] **Task 2 — Public widget posts BFF**
  `GET /api/widget/:id/posts` proxies Nest without a cookie or Bearer header.

- [x] **Task 3 — Helpers, schema, API client, hooks**
  Embed fallback, filters JSON parse, Zod form schema, fetch helpers, React
  Query keys `["widgets"]`, `["widgets", id]`, `["widget-preview", id]`.

- [x] **Task 4 — List page `/widgets`**
  Table Nome / Layout / Código de Embed, Copiar, Novo Widget, empty state.

- [x] **Task 5 — Create and edit form**
  `/widgets/new` and `/widgets/[id]/edit`. Create redirects to detail. 403
  shows the Nest plan-limit message.

- [x] **Task 6 — Detail, preview, copy, delete**
  `/widgets/[id]`: embed + Copiar, in-page preview from public posts, Editar,
  Excluir with confirm.

- [x] **Task 7 — Dashboard card + verification**
  Widgets summary card links to `/widgets`. `npm test`, `npm run lint`,
  `npm run build`.
